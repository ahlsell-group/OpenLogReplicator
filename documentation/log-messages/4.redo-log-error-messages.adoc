Errors indicating corrupted or unexpected redo log contents.

==== code 40001: "file: <file name> - block: <number> - invalid block size: <number>, header[1]: <number>"

Invalid block size in file header.
Verify file integrity.

==== code 40002: "file: <file name> - invalid header block number: <number>, expected: <number>"

Header block number mismatch.
Verify file integrity.

==== code 40003: "file: <file name> - invalid header[0]: <number>"

Invalid header value.
Verify file integrity.

==== code 40004: "file: <file name> - invalid header[28-31]: <number>, <number>, <number>, <number>"

Invalid header fields.
Verify file integrity.

==== code 40005: "file: <file name> - invalid block size: <number>, header[1]: <number>"

Header block size mismatch.
Verify file integrity.

==== code 40006: "file: <file name> - invalid database version: <number>"

Database version in header is unexpected.
You are trying to process redo log files from a  database version which is not tested and might produce unknown results.

==== code 40007: "file: <file name> - invalid database version: <number>, expected: <number>"

Database version mismatch.
Verify file source.

==== code 40008: "file: <file name> - invalid first scn value: <number>, expected: <number>"

First SCN in header does not match expected value.

==== code 40009: "file: <file name> - invalid next scn value: <number>, expected: <number>"

Next SCN in header mismatch.

==== code 40010: "file: <file name> - zero to read, start: <number>, end: <number>, scan: <number>"

Double-read error.
Verify file integrity.

==== code 40012: "file: <file name> - size: <number> is smaller than the <number> blocks of <number> bytes in its header, the file is truncated"

The archived redo log is shorter than its header says.
Reading it to its end would skip the missing redo, so the file is not processed; OpenLogReplicator retries opening it and stops with error 10009 if it stays short.
Check whether the file is still being copied or was truncated, and restore it from a backup if needed.

==== code 40013: "file: <file name> - <number> bytes read at offset: <number>, expected size: <number>, the file shrank or was removed while being read"

The archived redo log ended before the size it had when it was opened, usually because it was truncated or deleted (for example by a backup tool) while OpenLogReplicator read it.
OpenLogReplicator stops instead of moving on to the next sequence.
Restore the file and restart.
