As `big-txn-restart-task`, but the connector is paused once 6 000 rows are on the topic. While it is paused the task polls nothing and Connect keeps committing offsets, so the flushed offset is confirmed and OLR's confirmed position catches up with it. The task is then restarted and resumed: the CONTINUE position is the offset itself, so OLR resends nothing the task already emitted. Checks that a CONTINUE at exactly the offset (no replay to discard) delivers every row once, with one BEGIN and one END.
